# 선형독립 집합의 부분집합은 선형독립인가?

---

### 질문

- 선형독립인 집합의 부분집합도 선형독립인가?

---

$S$가 선형독립이고 $T \subset S$ 일 때, $T$도 선형독립일까? $S$가 $\lbrace \vec{v_1}, \vec{v_2}, ... , \vec{v_n} \rbrace$ 이라고 하자. $T$는 $\lbrace \vec{v_1}, \vec{v_2}, ... , \vec{v_t} \rbrace$ 이고, $T$에 속하지 않는 $S$의 벡터들은 $\lbrace \vec{v_{t+1}}, ... , \vec{v_n} \rbrace$ 이라고 하자. $T$가 선형독립이려면 다음 수식의 모든 계수가 0이어야 한다.

$$
c_1\vec{v_1} + c_2\vec{v_2} + ... + c_t\vec{v_t} = \vec{0}
$$

그런데 이 수식은 다음과 동일하다.

$$
c_1\vec{v_1} + c_2\vec{v_2} + ... + c_t\vec{v_t} + 0 \times \vec{v_{t+1}} + ... + 0 \times \vec{v_n}= \vec{0}
$$

$S$는 선형독립이기 때문에 위 수식의 모든 계수는 0이어야 한다. 따라서 $c_1 = c_2 = ... = c_t = 0$이므로 $T$는 선형독립이다. 주의할 점으로 역은 성립하지 않는다. 즉 부분집합이 선형독립이라고 해서 이를 포함하는 집합도 선형독립은 아니다. 그리고 선형독립인 집합들의 합집합도 선형독립이 아닐 수 있다. 예를 들어 $\lbrace \vec{v_1}, \vec{v_2}, \vec{v_3} \rbrace$가 선형독립일 때, $\lbrace \vec{v_1}, \vec{v_2} \rbrace, \lbrace 2\vec{v_2}, \vec{v_3} \rbrace$는 각각 선형독립이지만 합집합은 선형종속이다.
