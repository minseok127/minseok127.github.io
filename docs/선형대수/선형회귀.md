# 선형회귀를 벡터로 생각해보기

---

### 질문

- 선형회귀가 뭐지?
- 선형회귀를 벡터로 어떻게 설명할 수 있나?

---

주어진 값들은 n개의 입력 데이터 x들과 n개의 출력값 y들이다. 각각의 x들은 p개의 특성을 가지며, p차원 벡터로 표현할 수 있다. 주어진 x와 y들은 서로 대응된다.  즉 특정 입력 벡터 $\vec{x_1}$이 출력값 $y_1$에 대응된다. 선형회귀에서 하고자 하는 것은 모든 x들에 공통적으로 적용되는 가중치 벡터  $w$를 만드는 것이다. 이렇게 만들어진 가중치 벡터는 원래 입력 데이터 x와 일차식으로 결합되어 예측값 y를 만들어내고, 이 예측값 y와 실제 y의 차이를 최대한 작게 만드는 것이 선형회귀의 목적이다.

원래는 p차원이지만 가중치와 입력 데이터를 결합하는 수식에서 절편값까지 포함해야하므로, 입력 벡터를 p + 1차원으로 확장시켜서 첫 번째 성분값에 1을 부여하고, 가중치 벡터 또한 p + 1차원으로 확장시켜서 첫 번째 성분값에 일차식의 y절편값을 부여한다. 이처럼 실제 계산할 때는 p + 1차원으로 확장해야 하지만, 이 페이지에서는 편의를 위해 p차원으로 표현한다. 

$$
y_{pred} = w_1x_1 + w_2x_2 + ... + w_px_p + b
$$

주어진 각각의 데이터들에 대해 위와 같은 구조를 만들어야 한다. 모든 데이터 n개를 한꺼번에 표현하기 위해 p차원 벡터인 입력 데이터 n개를 $n \times p$ 행렬 $X$로 표현하고, n개의 출력값을 모아서 n차원 $Y$ 벡터로 표현한다. 가중치 벡터는 각각의 입력 벡터들에 곱해져야 하므로 p차원 벡터로 표현된다. 

$$
Y_{pred} = Xw
$$

n개의 데이터들을 한번에 표현하기 위해서 위와 같이 행렬을 사용해서 수식을 적는다. 선형회귀에서 하고자 하는 것은 결국 각각의 x에 대응되는 실제 y값과 y의 예측값의 차이를 최소화시키는 것이다. 이 차이를 수식으로 표현하면 $Y - Y_{pred} = Y - Xw$ 이렇게 표현된다. 이건 n차원 벡터니까, 결국 이 벡터의 길이를 최소화 시켜야 한다.

일반적으로 n이 p보다 훨씬 크니까, 이건 p차원 벡터인 w를 더 높은 차원인 n차원 공간으로 변환시키고, 원래 n차원에 있던 벡터인 Y와의 차이를 생각해보자. 기본적으로 w의 크기에는 제한이 없는 상황이다. 그러니 w가 변환되어서 위치할 수 있는 n차원 상의 공간은 결국 X의 열벡터들이 구성하는 공간으로 생각할 수 있다. 이 공간에서 Y와 가장 가까운 벡터는 Y를 해당 공간에 정사영 시킨 벡터이다. 즉 w를 X 행렬로 변환한 벡터가 Y를 X의 열벡터 공간에 정사영 시킨 것이 되도록 하면 된다. 이를 수식으로 나타내면 다음과 같다.

$$
X^T (Y - Xw) = 0 \iff X^TY = X^TXw
$$
